OPTCL Tender Statistics — Updated PWA

This package retains the existing OPTCL PWA structure, manifest, service worker and OPTCL icons, with the latest approved view-only dashboard in index.html.

Dashboard includes:
- Visual statistics with legends and figures
- No “Charts unavailable” section
- Dynamic tender statistics
- Search and filters
- Tender details
- Status, Category, Tender Type, Estimated Cost, Bidders Received
- Publication Date, Purchase Window, Bid Submission Close, Last Date of Receipt
- List of Bidders
- Technical Open and Cost Open qualification information where available
- Live data.json polling

For iPhone packaging, publish these files at the final HTTPS GitHub Pages URL and use that URL in PWABuilder.
